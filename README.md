# 🏡 Melbourne Housing Analysis

> What Factors Impact Housing Prices in Melbourne?

📊 A data-driven project exploring the variables that influence housing prices in Melbourne. Our goal was to derive insights from data and create a meaningful statistical analysis.

## 🔍 Project Overview

This project analyzes a dataset of Melbourne housing prices to uncover key features that affect home value. Using statistical tools and data visualization, we investigated:

- 🏘️ Location-based value differences  
- 📐 Property dimensions (land size, number of rooms, etc.)  
- 🏫 Proximity to schools and transportation  
- 📈 Market trends over time

---

## 📎 Dataset

Sourced from [Kaggle: Melbourne Housing Snapshot](https://www.kaggle.com/datasets/dansbecker/melbourne-housing-snapshot)
